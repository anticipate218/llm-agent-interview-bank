<a name="FND-ML-001"></a>

### FND-ML-001　基础 · 考频 ★★

大语言模型的预训练（在海量文本上预测下一个 token）通常被归为哪一类学习？

- **A.** 监督学习：训练数据中每个位置的目标 token 都经过人工标注和校对
- **B.** 自监督学习：标签（下一个 token）由文本自动构造，无需人工标注
- **C.** 强化学习：模型生成下一个 token 后，根据它是否与原文一致获得奖励来更新参数
- **D.** 无监督聚类：模型把语义相近的文本片段自动归入同一簇，再学习每个簇的表示

<details>
<summary>答案与解析</summary>

**答案：B**

**解析：**

**结论**：预训练是自监督学习。标签由数据自动构造：把文本右移一位，每个位置的「下一个 token」就是标签，不需要人工标注，所以能用上万亿 token 的原始文本。

自监督可以看作广义的无监督学习（不依赖人工标签），但训练形式与监督学习相同：有明确的预测目标，用交叉熵作为损失。BERT 的掩码语言模型、对比学习也属于自监督。

- A 错：标签不是人工标注的。人工标注的「指令-回答」对出现在后续的 SFT 阶段，那才是监督学习。
- C 错：强化学习出现在 RLHF / RLVR 等后训练阶段，依靠奖励信号，而不是逐 token 的标签。预训练直接用交叉熵最大化原文的似然，没有「生成—打分—奖励」的过程。
- D 错：预训练学的是下一个 token 的条件概率分布，不做聚类。

<sub>考点：监督与无监督学习</sub>

</details>

<a name="FND-ML-003"></a>

### FND-ML-003　进阶 · 考频 ★★★

一个分类模型在训练集上的准确率为 99%，在验证集上只有 78%。画学习曲线发现：随着训练样本增加，验证集准确率在持续上升，与训练集的差距在缩小。最合理的判断和对策是：

- **A.** 高偏差（欠拟合）：验证准确率偏低说明模型能力不足，应换用更复杂的模型或加特征
- **B.** 数据噪声过大：验证集的 78% 已接近贝叶斯最优准确率，属于不可约误差，难以再提升
- **C.** 高方差（过拟合）：继续加数据、加强正则化或降低模型复杂度
- **D.** 学习率过大导致训练没有收敛，验证集准确率波动，应降低学习率后重新训练

<details>
<summary>答案与解析</summary>

**答案：C**

**解析：**

**结论**：训练误差很低、验证误差高得多，二者差距大，是典型的高方差（过拟合）。学习曲线显示加数据能持续缩小差距，说明增加数据是有效的方向。

**判断方法**：
- 训练误差高、且与验证误差接近 → 高偏差（欠拟合）：模型能力不足，加数据帮助不大，应增加容量或特征、减弱正则。
- 训练误差低、验证误差高得多 → 高方差（过拟合）：模型记住了训练集的噪声，应加数据、做数据增强、加强正则（L2、Dropout、早停）或简化模型。

- A 错：训练集已达 99%，模型能力并不缺；验证准确率低是因为训练与验证差距大，而不是两者都低。
- B 错：如果是不可约噪声，训练集也很难达到 99%，加数据也不会让验证准确率持续上升。
- D 错：训练集准确率 99% 说明训练已经收敛得很好，学习率过大的典型表现是训练 loss 本身震荡、降不下去。

<sub>考点：偏差方差权衡、过拟合与欠拟合</sub>

</details>

<a name="FND-ML-006"></a>

### FND-ML-006　基础 · 考频 ★★★

一个房价回归模型在训练集和验证集上的误差都很高，而且两者很接近。下列措施中，**最可能**有效的是：

- **A.** 加大 L2 正则化系数，抑制训练集上的噪声，让训练误差与验证误差同时下降
- **B.** 收集更多与现有数据同分布的训练样本，让模型从更多例子中学到规律、降低误差
- **C.** 更早地停止训练（早停），避免模型在训练后期把噪声也拟合进去
- **D.** 增大模型容量或加入更有表达力的特征，并适当减弱正则化

<details>
<summary>答案与解析</summary>

**答案：D**

**解析：**

**结论**：训练误差本身就高，而且与验证误差接近，这是欠拟合（高偏差）：模型连训练数据都没拟合好，问题在于表达能力不足。

应对欠拟合要「加能力」：增大模型、加入有用的特征（如特征交叉、非线性变换）、减弱正则、训练更久。

- A 错：正则化限制模型能力，会让训练误差更高、欠拟合更严重。
- B 错：数据不足时，模型通常训练误差低而验证误差高；现在连训练集都拟合不好，加数据对偏差帮助不大（学习曲线上两条线已经贴在一起、都停在高位）。
- C 错：早停也是正则手段，用来防止过拟合，在这里适得其反。

<sub>考点：过拟合与欠拟合</sub>

</details>

<a name="FND-ML-007"></a>

### FND-ML-007　基础 · 考频 ★★★

L1 正则化容易得到稀疏解（很多参数恰好为 0），而 L2 正则化不会。下列解释正确的是：

- **A.** L1 的约束区域是顶点落在坐标轴上的菱形（高维为多面体），损失等值线最先碰到它的位置往往是顶点
- **B.** L1 惩罚 $|w|$ 的数值总比 L2 的 $w^2$ 大，对参数的压缩力度更强，所以参数更容易被压成 0
- **C.** L2 的约束区域是圆（球），等值线与它的切点一般落在坐标轴上，所以 L2 的解同样稀疏
- **D.** L1 惩罚的梯度与参数大小成正比，参数越小推力越小，所以参数会越来越慢地趋近于 0

<details>
<summary>答案与解析</summary>

**答案：A**

**解析：**

**结论**：稀疏性来自 L1 约束区域的「尖角」。

**几何视角**：带正则的优化等价于在约束区域内最小化损失。损失的等值线是一圈圈椭圆，从无约束最优点向外扩张，第一次碰到约束区域的点就是解。L1 球（二维是菱形）的顶点在坐标轴上、向外突出，椭圆最容易先碰到顶点，于是某些坐标为 0。L2 球是光滑的圆，切点一般不在坐标轴上。

**梯度视角**：L1 惩罚 $\lambda|w|$ 的（次）梯度大小恒为 $\lambda$，参数再小也会被以同样的力度推向 0，并能停在 0 处（0 处次梯度区间 $[-\lambda,\lambda]$ 能抵消小的损失梯度）；L2 惩罚 $\frac\lambda2w^2$ 的梯度 $\lambda w$ 随 $w$ 变小而变小，只会让参数无限接近 0，却不会恰好为 0。

- B 错：$|w|$ 与 $w^2$ 哪个大取决于 $|w|$ 是否大于 1，而稀疏性与惩罚值大小无关。
- C 错：圆的切点可以在任意方向上，一般不在坐标轴上。
- D 错：这描述的是 L2 的梯度 $\lambda w$；L1 的次梯度大小恒为 $\lambda$，与参数大小无关。

<sub>考点：L1与L2正则化</sub>

</details>

<a name="FND-ML-010"></a>

### FND-ML-010　基础 · 考频 ★★

关于 5 折交叉验证（5-fold cross validation），下列描述正确的是：

- **A.** 每次随机抽取 20% 的样本作为验证集、其余训练，重复 5 次，同一个样本可能多次被用于验证
- **B.** 数据分成 5 份，轮流用 4 份训练、1 份验证，共训练 5 个模型，每个样本恰好验证一次，结果取平均
- **C.** 只在全部数据上训练 1 个模型，再把数据分成 5 份分别评估，取 5 份成绩的平均作为最终成绩
- **D.** 交叉验证的平均成绩可以直接作为最终的测试成绩，因此用交叉验证调参后，不再需要独立的测试集

<details>
<summary>答案与解析</summary>

**答案：B**

**解析：**

**结论**：k 折交叉验证把数据分成互不重叠的 k 份，轮流把每一份当验证集，共训练 k 次。

优点是每个样本都既参与过训练、也参与过验证，在数据量不大时能更充分地利用数据，估计也更稳定（还可以报告 k 次结果的标准差）。代价是训练 k 次，计算量变为 k 倍。

- A 错：这是重复随机划分（Monte Carlo 交叉验证），不是 k 折。
- C 错：如果模型在全部数据上训练，再在其中一部分上评估，就是在训练集上评估，结果严重偏乐观。
- D 错：用交叉验证成绩来选超参数或选模型后，这个成绩已经被「挑选」过，偏乐观。要得到无偏的泛化估计，需要一个从未参与选择的独立测试集，或者使用嵌套交叉验证（外层评估、内层调参）。

<sub>考点：交叉验证</sub>

</details>

<a name="FND-ML-012"></a>

### FND-ML-012　挑战 · 考频 ★★

某数据集有 200 个样本、5000 个特征。同学先在**全部数据**上做了两步预处理：(1) 对每个特征做标准化；(2) 计算每个特征与标签的相关系数，保留相关性最高的 50 个特征。然后再用 5 折交叉验证评估逻辑回归，得到 95% 的准确率。对这个评估结果，下列判断正确的是：

- **A.** 没有问题：标准化与特征选择都只改变列、不改变样本，之后的 5 折交叉验证仍然独立，结果可信
- **B.** 只有标准化会泄露：它用到了验证折的均值和方差；特征选择只是挑选列，对评估没有影响
- **C.** 评估偏悲观：只保留 50 个特征丢掉了大量信息，模型用全部 5000 个特征时的真实表现应该更好
- **D.** 存在泄露：验证折的标签参与了特征挑选，结果偏乐观；标准化与特征选择应放进每一折内，只用训练折拟合

<details>
<summary>答案与解析</summary>

**答案：D**

**解析：**

**结论**：用标签做特征选择是最典型的泄露之一，而且在「样本少、特征多」时尤其严重。

5000 个特征里，即使全部是纯噪声，也总有一些特征碰巧与这 200 个样本的标签相关。在全量数据上挑出这 50 个特征时，验证折的标签已经参与了挑选；之后无论怎样交叉验证，模型都在利用这些「碰巧相关」的特征，准确率可能远高于随机，而上线后会回落到接近随机水平（Hastie 等在《统计学习基础》第 7.10.2 节专门讨论过这个错误做法）。

**正确做法**：凡是从数据中「学习」到的预处理（标准化的均值与方差、特征选择、PCA、缺失值填充的统计量、目标编码等），都必须作为模型的一部分，在每一折里只用训练折拟合，再应用到验证折。scikit-learn 的 `Pipeline` 配合 `cross_val_score` 可以自动保证这一点。

- A 错：特征选择用到了验证折的标签，这是泄露。
- B 错：恰好相反，标准化只用到了特征的分布（不用标签），泄露通常很轻微；基于标签的特征选择才是严重的泄露。
- C 错：泄露会让结果偏乐观，而不是偏悲观；只保留 50 个特征本身也不是这里的主要问题。

<sub>考点：交叉验证、特征工程</sub>

</details>

<a name="FND-ML-015"></a>

### FND-ML-015　进阶 · 考频 ★★

在单标签多分类任务（每个样本恰好属于一个类别）中，关于 macro-F1 与 micro-F1，下列说法正确的是：

- **A.** macro-F1 先把所有类别的 TP、FP、FN 分别加总，再用总数计算一个 F1
- **B.** micro-F1 先对每个类别单独计算 F1，再按各类别的样本数加权平均
- **C.** micro-F1 恰好等于准确率；类别不平衡时，macro-F1 更能反映少数类的表现
- **D.** 类别不平衡时，macro-F1 由样本多的大类主导，因此对少数类上的错误不敏感

<details>
<summary>答案与解析</summary>

**答案：C**

**解析：**

**结论**：micro 先汇总再算，macro 先分别算再平均。

- **micro-F1**：把所有类别的 TP、FP、FN 加总后计算。单标签多分类中，每个预测错误的样本，既是预测类别的一个 FP，又是真实类别的一个 FN，所以总 FP = 总 FN = 错误样本数，micro-P = micro-R = micro-F1 = 准确率。它由样本多的类别主导。
- **macro-F1**：每个类别单独计算 F1 后取算术平均，每个类别权重相同，少数类表现差会明显拉低分数。

例：9 个样本属于 A 类、1 个属于 B 类，模型全部预测为 A。准确率（= micro-F1）为 0.9；A 类 F1 约 0.947，B 类 F1 为 0，macro-F1 约 0.47。

- A 错：这是 micro 的做法。
- B 错：先逐类计算 F1 是 macro 的做法；再按样本数加权平均得到的是 weighted-F1，也不是 micro-F1。
- D 错：由大类主导的是 micro-F1（等于准确率）。macro-F1 给每个类别相同的权重，少数类表现差时会被明显拉低，上例中 macro-F1（0.47）就远低于 micro-F1（0.9）。

<sub>考点：分类评估指标</sub>

</details>

<a name="FND-ML-024"></a>

### FND-ML-024　进阶 · 考频 ★★★

逻辑回归用交叉熵（对数损失）而不是均方误差作为损失函数，最主要的原因是：

- **A.** 交叉熵对应伯努利极大似然且关于参数是凸的；换成均方误差，目标非凸，sigmoid 饱和时梯度还会被压得很小
- **B.** 均方误差在 sigmoid 输出上不可导：$(\sigma(z)-y)^2$ 在 $\sigma(z)=y$ 处有尖点，只能改用交叉熵
- **C.** 两种损失的最优解完全相同，选交叉熵只是因为它的梯度公式更简单、每步计算更快
- **D.** 交叉熵对标注错误的离群样本更稳健：它的损失随误差按对数增长，而均方误差按平方增长

<details>
<summary>答案与解析</summary>

**答案：A**

**解析：**

**结论**：交叉熵既有概率意义（极大似然），优化性质又好（凸、梯度不饱和）。

记 $p=\sigma(z)$，$z=w^\top x+b$。
- **交叉熵**：$\ell=-y\log p-(1-y)\log(1-p)$，$\partial\ell/\partial z=p-y$。预测越错，梯度越大，而且关于 $w$ 是凸函数，梯度下降能找到全局最优。
- **均方误差**：$\ell=\frac12(p-y)^2$，$\partial\ell/\partial z=(p-y)\,p(1-p)$。当 $y=1$ 而 $z$ 很负（$p\approx0$，预测完全错误）时，$p(1-p)\approx0$，梯度几乎为 0，模型「错得越离谱学得越慢」；而且目标关于 $w$ 非凸，可能陷入平坦区域。

- B 错：$(\sigma(z)-y)^2$ 是光滑函数，处处可导，没有尖点；MSE 的问题在于梯度性质不好、目标非凸。
- C 错：两种损失的最优解一般不同，优化难度也不同；两者的梯度公式都不复杂，计算速度也不是选择的理由。
- D 错：恰好相反。交叉熵的损失 $-\log p$ 在预测概率 $p\to0$ 时趋于无穷，对「高置信地预测错」的样本惩罚无上界，对标注噪声**更敏感**；MSE 的损失有上界 0.5，反而更稳健。

<sub>考点：线性回归与逻辑回归</sub>

</details>

<a name="FND-ML-028"></a>

### FND-ML-028　基础 · 考频 ★★★

关于 Bagging 与 Boosting，下列说法正确的是：

- **A.** Bagging 串行训练，每一轮加大前一轮错分样本的权重，主要降低偏差；Boosting 在自助采样的数据上并行训练，主要降低方差
- **B.** Bagging 在自助采样的数据上并行训练多个基学习器再平均，主要降方差；Boosting 串行修正前面模型的错误，主要降偏差
- **C.** 两者都主要用于降低偏差：Bagging 靠多个模型投票纠错，Boosting 靠逐轮加权纠错，区别只在训练方式
- **D.** Boosting 的基学习器通常是很深、不剪枝的树，Bagging 的基学习器通常是只有一次划分的决策树桩

<details>
<summary>答案与解析</summary>

**答案：B**

**解析：**

**结论**：Bagging 是「并行 + 平均」，降方差；Boosting 是「串行 + 纠错」，降偏差。

- **Bagging**（如随机森林）：每个基学习器在一份自助采样的数据上独立训练，最后投票或平均。平均可以抵消各模型的随机波动，所以适合低偏差、高方差的基学习器，例如很深、不剪枝的决策树。
- **Boosting**（如 AdaBoost、GBDT、XGBoost）：后一个学习器重点修正前面模型的错误（AdaBoost 加大错分样本的权重，GBDT 拟合负梯度），逐步降低偏差，适合高偏差、低方差的弱学习器，例如浅树。Boosting 迭代过多也可能过拟合，通常配合学习率（shrinkage）与早停。

- A 错：把两者的训练方式和作用完全说反了。
- C 错：Bagging 的平均（投票）抵消的是各模型的随机波动，主要降方差，基学习器的偏差基本保持不变。
- D 错：说反了，随机森林用深树，Boosting 常用浅树（AdaBoost 甚至常用决策树桩）。

<sub>考点：决策树与集成学习</sub>

</details>

<a name="FND-ML-032"></a>

### FND-ML-032　基础 · 考频 ★★

关于线性支持向量机（SVM），下列说法正确的是：

- **A.** 分类间隔为 $1/\lVert w\rVert^2$，最大化间隔等价于最大化 $\lVert w\rVert$
- **B.** 所有训练样本都会影响最终的分类超平面：对偶问题对每个样本都有约束，删除任何一个样本都会改变解
- **C.** 硬间隔 SVM 只看少数支持向量，因此对噪声和离群点不敏感，离群点很少会成为支持向量
- **D.** 超平面只由支持向量决定：删除对偶变量 $\alpha_i=0$ 的非支持向量后重新训练，解不变

<details>
<summary>答案与解析</summary>

**答案：D**

**解析：**

**结论**：SVM 的解只依赖支持向量。

对偶问题的解满足 $w=\sum_i\alpha_iy_ix_i$。由 KKT 互补松弛条件，只有落在间隔边界上（或在软间隔下违反间隔）的样本 $\alpha_i>0$，它们就是支持向量；其余样本 $\alpha_i=0$，对 $w$ 没有贡献，删掉后解不变。

- A 错：两条边界 $w^\top x+b=\pm1$ 之间的距离（间隔）为 $2/\lVert w\rVert$。最大化间隔等价于**最小化** $\frac12\lVert w\rVert^2$。
- B 错：只有支持向量会影响解；非支持向量对应的约束不起作用（$\alpha_i=0$），删掉它们解不变。
- C 错：恰好相反。硬间隔要求所有样本都被正确分开且在间隔之外，一个离群点就可能成为支持向量，大幅改变超平面，甚至让问题无解（线性不可分）。软间隔引入松弛变量和惩罚系数 $C$，就是为了容忍少量违反间隔的样本。

<sub>考点：支持向量机</sub>

</details>

<a name="FND-ML-037"></a>

### FND-ML-037　挑战 · 考频 ★★

关于高斯混合模型（GMM）与 K-means 的关系，下列说法正确的是：

- **A.** GMM 与 K-means 都保证收敛到全局最优：EM 与 Lloyd 迭代的每一步都单调改进目标函数，且不依赖初始化
- **B.** GMM 不需要预先指定簇的个数，簇数由 EM 根据似然自动确定，而 K-means 必须事先给定 K
- **C.** GMM 用 EM 做软分配，能拟合形状各异的椭圆簇；K-means 是各向同性协方差趋于 0 时的硬分配极限
- **D.** K-means 是协方差可以任意取值的 GMM 的特例，因此同样能拟合大小、方向各不相同的椭圆形簇

<details>
<summary>答案与解析</summary>

**答案：C**

**解析：**

**结论**：K-means 是 GMM 的一个极限特例。

GMM 的 EM 算法：
- **E 步**：计算责任度 $\gamma_{ik}=\dfrac{\pi_k\mathcal N(x_i\mid\mu_k,\Sigma_k)}{\sum_j\pi_j\mathcal N(x_i\mid\mu_j,\Sigma_j)}$，即样本 $i$ 属于第 $k$ 个分量的后验概率；
- **M 步**：用责任度加权，更新混合权重 $\pi_k$、均值 $\mu_k$ 与协方差 $\Sigma_k$。

令所有分量的协方差都为同一个各向同性矩阵 $\sigma^2I$ 并让 $\sigma\to0$，责任度会变成 0/1 的硬分配（最近的中心得 1），M 步退化为求均值，这正是 K-means。

- A 错：两者都只保证目标函数单调改进（GMM 的似然单调不减），只能收敛到局部最优，结果都依赖初始化（GMM 常用 K-means 的结果来初始化）。
- B 错：GMM 同样要指定分量个数。似然随分量数增加而单调不减，不能直接用来定簇数，通常用 BIC / AIC 等带复杂度惩罚的准则来选择。
- D 错：方向说反了，协方差可以任意时 GMM 更一般，K-means 只能划分出近似球形、大小相近的簇；K-means 对应的是「各向同性、方差相同且趋于 0」的特殊情形。

<sub>考点：聚类算法</sub>

</details>

<a name="FND-ML-038"></a>

### FND-ML-038　进阶 · 考频 ★★

关于主成分分析（PCA），下列说法正确的是：

- **A.** 量纲差异很大时应先标准化再做 PCA，否则第一主成分几乎就是数值方差最大的那个原始特征
- **B.** 主成分是协方差矩阵最小特征值对应的特征向量方向，沿这些方向投影的重构误差最小
- **C.** PCA 会利用标签信息，保留类间方差与类内方差之比最大的方向，因此属于有监督降维
- **D.** 做 PCA 前不需要单独中心化：直接对原始数据矩阵做 SVD，得到的右奇异向量就是主成分方向

<details>
<summary>答案与解析</summary>

**答案：A**

**解析：**

**结论**：PCA 寻找方差最大的方向，而方差依赖于单位，所以量纲差异大时必须先标准化。

收入的方差可能是 $10^8$ 量级，年龄只有 $10^2$ 量级，不标准化时第一主成分几乎完全指向「收入」轴，PCA 只是把方差最大的那一列挑了出来。标准化后做 PCA，等价于对**相关系数矩阵**做特征分解。

- B 错：主成分是**最大**特征值对应的特征向量，特征值等于该方向上投影的方差；保留最大特征值的方向，重构误差才最小，最小特征值的方向正是被丢弃的部分。
- C 错：PCA 不使用标签，是无监督的。最大化类间与类内方差之比的是线性判别分析（LDA）。PCA 保留的高方差方向不一定对分类有用。
- D 错：PCA 要求先中心化。直接对未中心化的数据矩阵做 SVD，第一方向会指向数据的均值方向，而不是方差最大的方向。

<sub>考点：降维与PCA</sub>

<a name="FND-ML-041"></a>

### FND-ML-041　基础 · 考频 ★★

把某个数值特征的单位从「元」换成「万元」（即整体除以 10000），下列哪类模型的训练结果基本不受影响？

- **A.** K 近邻（欧氏距离），因为它只看样本之间距离的相对大小
- **B.** 带 L2 正则化的逻辑回归：权重会自动放大 10000 倍来抵消
- **C.** RBF 核的支持向量机：核函数会自动适应特征的尺度
- **D.** 决策树，以及随机森林、GBDT 等树模型

<details>
<summary>答案与解析</summary>

**答案：D**

**解析：**

**结论**：树模型只关心特征值的**排序**，对单调变换不敏感。

决策树的分裂形如「特征 $\le$ 阈值」，把特征除以 10000，只需把阈值也除以 10000，划分结果完全相同，所以树模型通常不需要标准化。

- A 错：欧氏距离直接依赖特征尺度，缩小 10000 倍后，这个特征在距离中几乎不起作用，近邻的排序随之改变。
- B 错：不加正则时，权重可以相应放大 10000 倍来抵消缩放，预测不变；加了 L2 正则后，放大的权重会受到更重的惩罚，结果就变了。此外，各特征尺度差异大还会让梯度下降收敛变慢。
- C 错：RBF 核 $e^{-\gamma\lVert x-z\rVert^2}$ 依赖距离，同样受尺度影响；$\gamma$ 是固定的超参数，不会随特征尺度自动调整。

**经验**：基于距离、内积、梯度下降或正则化的模型（KNN、SVM、线性模型、神经网络、K-means、PCA）都应先做标准化或归一化；树模型一般不需要。

<sub>考点：特征工程</sub>

</details>

<a name="FND-ML-009"></a>

### FND-ML-009　进阶 · 考频 ★★

关于 L1 与 L2 正则化，下列说法**正确**的有：

- **A.** $\lambda>0$ 时，即使 $X^\top X$ 奇异，岭回归闭式解中的 $X^\top X+\lambda I$ 也一定可逆
- **B.** 特征高度相关时，Lasso 往往只随机保留其中一个、结果不稳定；Elastic Net 可以缓解
- **C.** 从贝叶斯角度看，L1 正则对应参数的零均值拉普拉斯先验，L2 正则对应零均值高斯先验
- **D.** L1 正则 $\lambda\lVert w\rVert_1$ 处处可导，用普通梯度下降就能让参数恰好停在 0 上，得到稀疏解
- **E.** L2 正则会把大量参数精确地压成 0，因此和 L1 一样常用于特征选择，只是收缩得更平滑

<details>
<summary>答案与解析</summary>

**答案：ABC**

**解析：**

**结论**：A、B、C 正确。

- A 对：$X^\top X$ 半正定，特征值 $\ge0$；加上 $\lambda I$ 后特征值 $\ge\lambda>0$，矩阵正定可逆。这也是岭回归能处理多重共线性的原因。
- B 对：若两个特征几乎相同，L1 惩罚下「全给一个」与「两个平分」的代价相近，Lasso 倾向于只选一个，选哪个对数据扰动很敏感。Elastic Net 的 L2 部分鼓励相关特征共享权重（分组效应）。
- C 对：MAP 估计中，负对数先验就是正则项：拉普拉斯先验 $p(w)\propto e^{-|w|/b}$ 对应 $\lVert w\rVert_1$，高斯先验对应 $\lVert w\rVert_2^2$。
- D 错：$|w|$ 在 0 处不可导。普通梯度下降的参数会在 0 附近来回跳，几乎不会恰好落在 0 上。要得到精确的稀疏解，需要用次梯度、坐标下降或近端梯度（软阈值）等方法。
- E 错：说反了，产生稀疏解、用于特征选择的是 L1。L2 只做等比例收缩，参数会变小，但几乎不会恰好为 0。

**怎么选**：需要特征选择、可解释性，或者相信只有少数特征有用时，选 L1；特征很多且彼此相关、希望稳定地整体收缩时，选 L2；两者兼顾时选 Elastic Net。深度学习中最常用的是 L2 型的权重衰减。

<sub>考点：L1与L2正则化</sub>

</details>

<a name="FND-ML-017"></a>

### FND-ML-017　进阶 · 考频 ★★★

关于 ROC 曲线下面积（AUC），下列说法**正确**的有：

- **A.** AUC 依赖于决策阈值的选取：阈值取 0.5 时 AUC 最大，阈值偏离 0.5 时 AUC 下降
- **B.** AUC 越高，模型输出的概率越接近真实概率：AUC = 1 时预测概率已经完全校准
- **C.** AUC 对类别比例敏感：把测试集中的每个负样本都复制一份（得分不变），AUC 会随之下降
- **D.** AUC = 0.5 相当于随机排序；若 AUC 明显小于 0.5，把得分取相反数即可得到大于 0.5 的 AUC
- **E.** AUC 等于随机抽一对正、负样本时正样本得分更高的概率（得分相同记 1/2）

<details>
<summary>答案与解析</summary>

**答案：DE**

**解析：**

**结论**：D、E 正确。AUC 只衡量**排序**能力。

- A 错：ROC 曲线是把阈值从高到低扫一遍得到的，AUC 汇总了所有阈值，与某个具体阈值无关，也就谈不上「阈值取多少时 AUC 最大」。
- B 错：把所有得分都乘以 0.1，AUC 不变，概率却严重偏离真实值；即使 AUC = 1，输出的概率也可以完全没有校准。校准要用可靠性图、ECE、Brier 分数等指标来评估。
- C 错：每个负样本复制一份后，所有「正—负」样本对都按相同的倍数增加，「正样本得分高于负样本」的比例不变，AUC 也不变。ROC 曲线的横纵轴（FPR、TPR）各自只在一个类别内部计算，所以对类别比例不敏感；精确率和 PR 曲线才会随正负比例变化。同理，对得分做任何严格单调递增的变换（如取对数），也不改变 AUC。
- D 对：AUC 小于 0.5 说明排序方向反了，取反后 AUC 变为 $1-\text{AUC}$。实际中出现这种情况，往往是标签或得分的方向弄反了。
- E 对：这是 AUC 的概率解释，等价于 Mann–Whitney U 统计量除以 $n_{pos}n_{neg}$。

**追问**：数据中只有正样本（或只有负样本）时 AUC 无定义，因为没有「正负样本对」可比较。这时应报错或返回空值，而不是返回 0.5 或 1。

<sub>考点：ROC与AUC</sub>

<a name="FND-ML-021"></a>

### FND-ML-021　进阶 · 考频 ★★★

训练一个正样本只占 1% 的二分类模型，下列做法中**合理**的有：

- **A.** 用 PR-AUC、正类的召回率与精确率等指标来选择模型，而不是只看准确率
- **B.** 为了评估公平，对测试集也做过采样，使正负样本数量相等后再计算精确率、召回率等指标
- **C.** 在损失中给少数类更大的权重，或使用 Focal Loss 降低大量易分样本的权重
- **D.** 对少数类过采样（如 SMOTE 在少数类样本的近邻之间插值生成新样本），或对多数类欠采样
- **E.** 训练后在验证集上，根据业务目标（如要求召回率不低于 90%）重新选择决策阈值，而不是固定用 0.5

<details>
<summary>答案与解析</summary>

**答案：ACDE**

**解析：**

**结论**：A、C、D、E 合理。处理不平衡可以从四个层面入手：数据层（重采样）、算法层（加权损失）、决策层（调阈值）、评估层（选对指标）。

- A 对：准确率会被多数类主导（全部预测为负类就有 99% 的准确率），应使用召回率、精确率、F1、PR-AUC 或业务代价来选模型。

- C 对：类别加权让少数类的错误代价更高；Focal Loss（Lin 等, 2017, arXiv:1708.02002）用 $(1-p_t)^\gamma$ 压低易分样本的损失，让训练聚焦难样本。
- D 对：过采样能增加少数类的样本，SMOTE 通过插值减少简单复制带来的过拟合；欠采样能加快训练，但会丢失信息。注意重采样只能在训练集上做，并且要在划分数据之后进行。
- E 对：不平衡数据上，最优阈值通常不是 0.5，应根据代价或业务约束，在验证集上选择。

**注意**：重采样或加权之后，模型输出的概率会偏离真实的后验概率；如果下游需要概率本身，需要重新校准。

<a name="FND-ML-029"></a>

### FND-ML-029　进阶 · 考频 ★★★

关于 GBDT、XGBoost 与随机森林，下列说法**正确**的有：

- **A.** GBDT 每一轮用回归树拟合损失关于当前预测的负梯度，平方损失下它就是残差
- **B.** XGBoost 对损失做二阶泰勒展开，同时用到一阶与二阶导数，并对叶子数与叶子权重加正则
- **C.** GBDT 每棵树只学习残差的一小部分，增加树的数量不会导致过拟合，因此不需要早停
- **D.** 随机森林在每次分裂时，只从随机抽取的一部分特征中选择最优划分，主要是为了降低单棵树的偏差
- **E.** GBDT 的各棵树都直接拟合原始标签、彼此独立，可以像随机森林一样完全并行地训练

<details>
<summary>答案与解析</summary>

**答案：AB**

**解析：**

**结论**：A、B 正确。

- A 对：GBDT 是函数空间中的梯度下降。平方损失 $\frac12(y-F)^2$ 的负梯度为 $y-F$，就是残差；换成对数损失、Huber 损失等，同一框架照样适用。
- B 对：XGBoost（Chen 与 Guestrin, 2016, arXiv:1603.02754）的目标为 $\sum_i[g_if(x_i)+\frac12h_if(x_i)^2]+\gamma T+\frac12\lambda\sum_jw_j^2$，由此得到叶子权重的闭式解 $w_j^*=-G_j/(H_j+\lambda)$ 与划分增益公式。
- C 错：每增加一棵树都会更贴合训练集，树太多同样会过拟合；学习率让每棵树只走一小步，只能减缓、不能消除过拟合。实践中用学习率（shrinkage）、子采样、限制树深，并在验证集上早停。
- D 错：特征子采样是随机森林在 Bagging 之外的第二重随机性，目的是**降低树与树之间的相关性**，而不是降低偏差。每次分裂可选的特征变少，单棵树通常反而略差（偏差略升）；但 $n$ 棵树平均后的方差为 $\rho\sigma^2+\frac{1-\rho}{n}\sigma^2$，降低相关系数 $\rho$ 才能让平均更有效。随机森林的偏差基本就是单棵深树的偏差，它主要降低的是方差。
- E 错：GBDT 的第 $t$ 棵树拟合的是前 $t-1$ 棵树累加后的负梯度，而不是原始标签，树与树之间是串行的。XGBoost、LightGBM 的并行发生在**单棵树内部**（并行地为不同特征寻找最佳划分点），不是多棵树同时训练。

<sub>考点：决策树与集成学习　｜　出处：论文：arXiv:1603.02754（https://arxiv.org/abs/1603.02754）</sub>

</details>

<a name="FND-ML-042"></a>

### FND-ML-042　进阶 · 考频 ★★

某推荐模型有一个「城市」特征，共约 3000 个取值，分布长尾。关于如何编码这类高基数类别特征，下列说法**正确**的有：

- **A.** 出现次数很少的城市信息量太少、只会引入噪声，应在训练前直接删除这些样本，以免模型过拟合
- **B.** 特征哈希把类别映射到固定数量的桶，内存固定、能处理新城市，代价是不同城市可能碰撞
- **C.** 对线性模型使用标签编码（把城市映射为 0、1、2……），可以把信息压缩到一个数值特征里，是首选做法
- **D.** 目标编码若直接在全部训练数据上计算，会把样本自身的标签泄露进特征；应按折外方式计算，并对低频城市做平滑
- **E.** one-hot 得到高维稀疏特征，线性模型处理得很好，树模型却分裂效率低、容易长成很深的不平衡树

<details>
<summary>答案与解析</summary>

**答案：BDE**

**解析：**

**结论**：B、D、E 正确。

- A 错：低频城市的样本仍然带有其他特征和标签的信息。应把低频类别合并成「其他」类，或依靠平滑与嵌入共享统计强度；直接删除样本会丢掉数据并引入偏差。
- B 对：哈希把任意取值映射到 $M$ 个桶，内存固定、天然支持新类别，适合超大规模的稀疏特征；碰撞会带来少量信息损失。
- C 错：标签编码给类别强加了大小顺序（「城市 2 > 城市 1」），线性模型会把它当作有序的数值，没有意义。树模型对标签编码相对宽容，但最好使用原生的类别特征支持（如 LightGBM、CatBoost）。
- D 对：目标编码很强，但样本自身的标签参与了自己特征的计算，训练集上会过分乐观。常用折外计算，并按 $\frac{n\bar y_c+m\bar y}{n+m}$ 向全局均值收缩（$m$ 为平滑强度），低频类别更接近全局均值。CatBoost 的有序目标统计（ordered target statistics）也是为了解决同一个泄露问题。
- E 对：3000 维的 one-hot 对线性模型、因子分解机都很自然；对树模型，每个二值列只覆盖很少的样本，单次分裂的增益很小，树往往要长得很深。

深度模型中，最常用的方法是为每个类别学习一个嵌入向量（embedding）。

## 判断题

<a name="FND-ML-005"></a>

### FND-ML-005　挑战 · 考频 ★

随着模型参数量增加，测试误差先下降、后上升；越过插值阈值（参数刚好多到能把训练集拟合到零误差）之后，继续增加参数会让测试误差进一步上升，所以参数量远大于训练样本数的模型，泛化比插值阈值附近的模型更差。

<details>
<summary>答案与解析</summary>

**答案：❌ 错误**

**解析：**

**错误**。经典的 U 形曲线描述的是插值阈值之前的情形，阈值之后的走势恰好相反。

**双下降（double descent）**：Belkin 等（2019, arXiv:1812.11118）发现，模型复杂度越过「插值阈值」（刚好能把训练集拟合到零误差）后，测试误差会**再次下降**，而且常常低于 U 形曲线的最低点。Nakkiran 等（2019, arXiv:1912.02292）在深度网络上观察到了同样的现象，不仅随模型大小出现，也会随训练轮数出现。测试误差的峰值通常就出现在插值阈值附近：此时模型「刚好够」拟合训练数据，只能用很扭曲的方式去拟合噪声；参数远多于样本的模型往往泛化更好。

**原因**：参数远多于样本时，能完全拟合训练集的解有无穷多个；梯度下降等训练方法带有隐式正则化，倾向于找到「范数较小、较平滑」的那个解，泛化反而更好。

**正确理解**：偏差-方差分解本身仍然成立，只是方差不一定随参数量单调增大。「参数比样本多就一定过拟合」不成立，这也是大模型能在过参数化区域良好泛化的背景之一。

<sub>考点：偏差方差权衡、过拟合与欠拟合　｜　出处：论文：arXiv:1812.11118（https://arxiv.org/abs/1812.11118）、arXiv:1912.02292（https://arxiv.org/abs/1912.02292）</sub>

</details>

<a name="FND-ML-011"></a>

### FND-ML-011　基础 · 考频 ★★

用过去三年的每日销量预测未来的销量。如果把所有样本随机打乱后做 5 折交叉验证，得到的误差通常会低估模型上线后的预测误差，应当改用按时间顺序划分的前向验证。

<details>
<summary>答案与解析</summary>

**答案：✅ 正确**

**解析：**

**正确**。随机打乱会让训练折中出现验证折「未来」时刻的数据，模型等于偷看了未来，交叉验证的误差偏乐观。另外，时间上相邻的样本高度相关，随机划分后训练集与验证集几乎「同质」，也会让误差偏低。

**正确做法**：按时间顺序划分，用过去预测未来。
- 前向滚动验证（forward chaining / expanding window）：依次用 $[1..t]$ 训练、$[t+1..t+h]$ 验证，再把窗口向后推；scikit-learn 的 `TimeSeriesSplit` 就是这种方式。
- 训练集与验证集之间可以留出间隔（gap），避免标签窗口重叠造成的泄露。
- 特征也必须只用预测时刻之前的数据计算（如滞后特征、滑动均值不能包含当天及以后的值）。

同理，同一个用户的多条样本要整组划分（GroupKFold），否则模型会「认出」用户而不是学到规律。

<sub>考点：交叉验证</sub>

</details>

<a name="FND-ML-018"></a>

### FND-ML-018　进阶 · 考频 ★★

在正样本极少（例如只占 0.1%）的场景下，模型的 ROC 曲线和 AUC 可能看起来很好，精确率却很低；此时 PR 曲线（或平均精度 AP）通常比 ROC 曲线更能反映模型在正类上的实际表现。

<details>
<summary>答案与解析</summary>

**答案：✅ 正确**

**解析：**

**正确**。ROC 的 TPR 与 FPR 都在各自的类别内部计算，不受正负样本比例的影响；也正因如此，在极度不平衡时，ROC 会掩盖大量的误报。

**例子**：10 万个负样本、100 个正样本。某个阈值下 TPR = 90%、FPR = 1%，ROC 上这个点 $(0.01,0.9)$ 看起来非常好。可是 1% 的 FPR 意味着 1000 个误报，而真正例只有 90 个，精确率只有 $90/1090\approx8.3\%$，几乎不可用。

PR 曲线以精确率为纵轴，直接反映「报出来的有多少是真的」，对这种情况很敏感，因此在正类稀少、关注正类的场景中更有信息量（Saito 与 Rehmsmeier, 2015, PLoS ONE）。实践中两者常一起报告，正类稀少时以 PR-AUC（或 AP）为主。另外注意：随机分类器的 PR-AUC 约等于正类比例（这里是 0.001），而不是 0.5。

<sub>考点：ROC与AUC、类别不平衡</sub>

</details>

<a name="FND-ML-023"></a>

### FND-ML-023　挑战 · 考频 ★★

用类别权重或过采样训练不平衡数据后，模型输出的概率仍然是真实后验概率的良好估计，可以直接作为风险概率，用于计算期望损失。

<details>
<summary>答案与解析</summary>

**答案：❌ 错误**

**解析：**

**错误**。把正样本过采样 $w$ 倍（或把它的损失权重设为 $w$），相当于把训练时的先验几率放大了 $w$ 倍。模型学到的后验几率也被放大约 $w$ 倍，输出的概率系统性偏高。

**先验校正**：设模型输出 $p'$，真实后验约为
$$p=\frac{p'}{p'+w(1-p')}$$
例如真实欺诈率 1%，训练时把正样本过采样 10 倍。模型输出 0.5，对应的真实概率只有 $0.5/(0.5+10\times0.5)\approx9.1\%$。

**实践**：
- 只需要排序（如取前 K 名、看 AUC）时，单调的校正不改变排序，可以不管；
- 需要概率本身（期望损失、多个模型分数融合、展示风险值）时，要在保持真实分布的验证集上重新校准：用上面的先验校正，或用 Platt 缩放、等渗回归（isotonic regression），并用可靠性图或 ECE 检查效果。

<sub>考点：类别不平衡</sub>

</details>

### FND-ML-026　进阶 · 考频 ★★

对无截距的一元线性回归 $y=wx$，有 3 个样本 $(x,y)=(1,2),(2,4),(3,7)$。最小二乘解 $w=$ ____（保留两位小数）；若最小化 $\sum_i(y_i-wx_i)^2+\lambda w^2$ 且 $\lambda=1$（岭回归），解为 $w=$ ____（保留两位小数）。

<details>
<summary>答案与解析</summary>

**答案：** (1) 2.21 / 31/14；(2) 2.07 / 31/15

**解析：**

**最小二乘**：令 $\frac{d}{dw}\sum(y_i-wx_i)^2=-2\sum x_i(y_i-wx_i)=0$，得
$$w=\frac{\sum x_iy_i}{\sum x_i^2}=\frac{2+8+21}{1+4+9}=\frac{31}{14}\approx2.21$$

**岭回归**：令 $-2\sum x_i(y_i-wx_i)+2\lambda w=0$，得
$$w=\frac{\sum x_iy_i}{\sum x_i^2+\lambda}=\frac{31}{15}\approx2.07$$

它们分别是矩阵形式 $w=(X^\top X)^{-1}X^\top y$ 与 $w=(X^\top X+\lambda I)^{-1}X^\top y$ 在一维时的特例。可以看到，L2 正则在分母上加了 $\lambda$，把系数向 0 收缩。

<a name="FND-ML-033"></a>

### FND-ML-033　进阶 · 考频 ★★

多项式核 $K(x,z)=(x^\top z+1)^2$ 对应一个显式的特征映射 $\phi$，满足 $K(x,z)=\phi(x)^\top\phi(z)$。取维度最小的 $\phi$（每个不同的单项式只占一维），当 $x\in\mathbb{R}^2$ 时，$\phi(x)$ 的维度为 ____；当 $x\in\mathbb{R}^{100}$ 时，$\phi(x)$ 的维度为 ____。

<details>
<summary>答案与解析</summary>

**答案：** (1) 6；(2) 5151

**解析：**

**展开**：$(x^\top z+1)^2=\sum_{i,j}x_ix_jz_iz_j+2\sum_ix_iz_i+1$，对应的特征包括：
- 平方项 $x_i^2$：$d$ 个；
- 交叉项 $\sqrt2x_ix_j$（$i<j$）：$d(d-1)/2$ 个；
- 一次项 $\sqrt2x_i$：$d$ 个；
- 常数 1：1 个。

合计 $\frac{(d+1)(d+2)}{2}$，即 $\binom{d+2}{2}$。$d=2$ 时为 6，例如 $\phi(x)=(x_1^2,x_2^2,\sqrt2x_1x_2,\sqrt2x_1,\sqrt2x_2,1)$；$d=100$ 时为 $102\times101/2=5151$。

满足条件的 $\phi$ 并不唯一：若不合并 $x_ix_j$ 与 $x_jx_i$，按 $\sum_{i,j}$ 逐项展开会得到 $d^2+d+1$ 维的映射（$d=2$ 时为 7）。题目问的是合并重复项之后的最小维度。

**核技巧的意义**：直接计算 $K(x,z)$ 只需 $O(d)$ 次运算（一次内积再平方），而显式构造特征需要 $O(d^2)$ 维；多项式次数更高时差距更大。RBF 核 $e^{-\gamma\lVert x-z\rVert^2}$ 对应的特征空间是无穷维的，根本无法显式构造，却可以直接计算核函数值。SVM 的对偶问题与预测函数只依赖样本之间的内积，这是核技巧能够使用的前提。

<sub>考点：支持向量机</sub>

</details>

## 计算题

<a name="FND-ML-008"></a>

### FND-ML-008　进阶 · 考频 ★★

设计矩阵各列正交且单位化（$X^\top X=I$），普通最小二乘的解为 $\hat w^{OLS}=(3,\ 0.5,\ -1.2)$。分别求：
(1) Lasso：最小化 $\frac12\lVert y-Xw\rVert^2+\lambda\lVert w\rVert_1$；
(2) 岭回归：最小化 $\frac12\lVert y-Xw\rVert^2+\frac\lambda2\lVert w\rVert_2^2$。
取 $\lambda=1$，两者的解各是多少？

<details>
<summary>答案与解析</summary>

**答案：Lasso：$(2,\ 0,\ -0.2)$；岭回归：$(1.5,\ 0.25,\ -0.6)$**

**解析：**

**化简**：$X^\top X=I$ 时，$\frac12\lVert y-Xw\rVert^2=\frac12\lVert w-\hat w^{OLS}\rVert^2+\text{常数}$，问题拆成每个坐标独立的一维问题。记 $a=\hat w^{OLS}_j$。

**(1) Lasso**：最小化 $\frac12(w-a)^2+\lambda|w|$，解为**软阈值**：
$$w^*=\mathrm{sign}(a)\max(|a|-\lambda,0)$$
$a=3\to2$；$a=0.5$ 时 $|a|<\lambda$，结果为 $0$；$a=-1.2\to-0.2$。所以解为 $(2,0,-0.2)$。

**(2) 岭回归**：最小化 $\frac12(w-a)^2+\frac\lambda2w^2$，令导数 $(w-a)+\lambda w=0$，得 $w^*=a/(1+\lambda)$。结果为 $(1.5,0.25,-0.6)$。

**对比**：
- L1 把每个系数**平移** $\lambda$ 后截断：小系数直接变成 0（特征选择），大系数也被减去同样的量（有偏）。
- L2 把每个系数**按比例**缩小为 $1/(1+\lambda)$：不会产生 0，各系数保持相对大小。

这个闭式解也是坐标下降法、近端梯度法（ISTA）求解 Lasso 时每一步所用的软阈值算子。

<sub>考点：L1与L2正则化</sub>

</details>

### FND-ML-013　基础 · 考频 ★★★

一个二分类模型在 1000 个测试样本上的混淆矩阵为：TP = 40，FP = 10，FN = 20，TN = 930。计算准确率、精确率、召回率、F1 与假正率（FPR）。

<details>
<summary>答案与解析</summary>

**答案：准确率 97%，精确率 80%，召回率约 66.7%，F1 约 0.727，FPR 约 1.06%**

**解析：**

1. 准确率 $=\dfrac{TP+TN}{\text{总数}}=\dfrac{40+930}{1000}=97\%$
2. 精确率 $P=\dfrac{TP}{TP+FP}=\dfrac{40}{50}=80\%$：预测为正的样本中，真正为正的比例。

5. FPR $=\dfrac{FP}{FP+TN}=\dfrac{10}{940}\approx1.06\%$。

<a name="FND-ML-019"></a>

### FND-ML-019　进阶 · 考频 ★★★

某模型对 7 个样本的打分如下：正样本 3 个，得分为 0.9、0.7、0.4；负样本 4 个，得分为 0.8、0.4、0.3、0.1。按「正负样本对」的定义计算 AUC（得分相同的样本对记 0.5）。

<details>
<summary>答案与解析</summary>

**答案：AUC = 9.5 / 12 ≈ 0.792**

**解析：**

正负样本对共 $3\times4=12$ 对，逐个正样本统计：
- 0.9：高于全部 4 个负样本，计 4；
- 0.7：高于 0.4、0.3、0.1，低于 0.8，计 3；
- 0.4：低于 0.8（0）、与 0.4 相同（0.5）、高于 0.3 与 0.1（2），计 2.5。

合计 $4+3+2.5=9.5$，AUC $=9.5/12\approx0.792$。

**秩和公式验证**：把 7 个得分从小到大排列，秩依次为：0.1→1，0.3→2，两个 0.4 并列取平均秩 3.5，0.7→5，0.8→6，0.9→7。正样本秩和 $=7+5+3.5=15.5$，
$$\text{AUC}=\frac{15.5-\frac{3\times4}{2}}{3\times4}=\frac{15.5-6}{12}=0.792$$
其中 $\frac{n_{pos}(n_{pos}+1)}{2}=6$。秩和公式只需排序一次，复杂度 $O(n\log n)$，适合大规模数据；两两比较是 $O(n_{pos}n_{neg})$。

某节点有 10 个样本（5 正 5 负），有两种候选划分：

<details>
<summary>答案与解析</summary>

### FND-ML-030　挑战 · 考频 ★★

用 XGBoost 做二分类（对数损失）。当前模型对某节点内 4 个样本的原始得分（logit）都为 0，即预测概率都是 0.5，标签依次为 1、1、0、1。对数损失关于原始得分的一阶导为 $g=p-y$，二阶导为 $h=p(1-p)$。正则参数 $\lambda=1$、$\gamma=0.1$。
(1) 若该节点作为叶子不再分裂，最优叶子权重 $w^*$ 是多少？
(2) 若把它划分为 {样本 1, 样本 2} 与 {样本 3, 样本 4}，分裂增益是多少？是否应该分裂？
(3) 若 $\gamma=0$，分裂后两个叶子的最优权重各是多少？

<details>
<summary>答案与解析</summary>

**答案：(1) $w^*=0.5$；(2) 增益 $=1/12-0.1\approx-0.017<0$，不分裂；(3) 左叶子 $2/3\approx0.667$，右叶子 0**

**解析：**

**公式**（Chen 与 Guestrin, 2016, arXiv:1603.02754）：对损失做二阶泰勒展开后，叶子 $j$ 的最优权重与对应的目标值为
$$w_j^*=-\frac{G_j}{H_j+\lambda},\qquad \text{Obj}^*=-\frac12\sum_j\frac{G_j^2}{H_j+\lambda}+\gamma T$$
其中 $G_j$、$H_j$ 是落在叶子 $j$ 上的样本的 $g$、$h$ 之和，$T$ 为叶子数。分裂增益为
$$\text{Gain}=\frac12\left[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right]-\gamma$$

**计算**：$p=0.5$，所以 $g=(-0.5,-0.5,0.5,-0.5)$，每个样本 $h=0.25$。
1. $G=-1$，$H=1$，$w^*=-(-1)/(1+1)=0.5$。正的权重会把这些样本的 logit 往「正类」方向推，与 4 个样本中 3 个为正类一致。
2. 左：$G_L=-1$，$H_L=0.5$；右：$G_R=0$，$H_R=0.5$。
   $\text{Gain}=\frac12\left[\frac{1}{1.5}+0-\frac{1}{2}\right]-0.1=\frac12\times\frac16-0.1=\frac1{12}-0.1\approx-0.017<0$，不分裂。
3. $\gamma=0$ 时增益为 $1/12>0$，应该分裂：$w_L=-(-1)/(0.5+1)=2/3\approx0.667$，$w_R=-0/(0.5+1)=0$。

**解读**：
- $\gamma$ 相当于「每多一片叶子要付出的代价」，增益不超过 $\gamma$ 就不分裂，起到预剪枝的作用；
- $\lambda$ 出现在分母上，把叶子权重向 0 收缩，样本少（$H$ 小）的叶子收缩得更明显；
- 实际更新时还要乘以学习率 $\eta$（如 0.1），即 $F\leftarrow F+\eta w$。

<sub>考点：决策树与集成学习　｜　出处：论文：arXiv:1603.02754（https://arxiv.org/abs/1603.02754）</sub>

</details>

### FND-ML-039　基础 · 考频 ★★

对一个 5 维数据集做 PCA，协方差矩阵（按 $1/n$ 归一化）的特征值从大到小为 4.0、2.0、1.0、0.5、0.5。求：
(1) 前 2 个主成分的累计解释方差比例；
(2) 要保留至少 90% 的方差，最少需要几个主成分；
(3) 只保留前 2 个主成分时，平均每个样本的平方重构误差。

<details>
<summary>答案与解析</summary>

**答案：(1) 75%；(2) 4 个；(3) 2.0**

**解析：**

总方差等于特征值之和：$4+2+1+0.5+0.5=8$。

1. 前 2 个：$(4+2)/8=75\%$。
2. 累计比例依次为 50%、75%、87.5%、93.75%、100%，第一次达到 90% 是在 $k=4$。
3. 平均平方重构误差等于被丢弃方向上的方差之和：$1+0.5+0.5=2.0$，占总方差的 25%，与 (1) 互补。

**原理**：PCA 的两种等价定义——在 $k$ 维子空间上投影方差最大，与重构误差最小——正是由「总方差 = 保留部分 + 丢弃部分」联系起来的。按 $1/(n-1)$ 归一化时，特征值整体乘以 $n/(n-1)$，比例不变。实践中常用「累计解释方差达到 90% 或 95%」来选择 $k$，或者看碎石图（scree plot）的拐点。

### FND-ML-036　进阶 · 考频 ★★

下面的代码在一维数据上，从两组不同的初始中心运行 K-means（$K=2$），输出最终的中心与簇内平方误差和（SSE）。输出是什么？

```python
import numpy as np

def kmeans_1d(x, centers, iters=10):
    c = np.array(centers, dtype=float)
    for _ in range(iters):
        labels = np.abs(x[:, None] - c[None, :]).argmin(axis=1)
        c = np.array([x[labels == j].mean() for j in range(len(c))])
    sse = float(((x - c[labels]) ** 2).sum())
    return c.tolist(), sse

x = np.array([1, 2, 3, 8, 9, 10, 25], dtype=float)
print(kmeans_1d(x, [1, 9]))
print(kmeans_1d(x, [1, 25]))
```

<details>
<summary>答案与解析</summary>

**答案（程序输出）：**

```text

([5.5, 25.0], 77.5)
```

**解析：**

**初始中心 [1, 9]**：
- 第 1 轮：1、2、3 离 1 近；8、9、10、25 离 9 近（25 到 9 的距离 16，比到 1 的距离 24 小）。新中心为 2 与 $(8+9+10+25)/4=13$。

- 1～10 都离 1 更近（10 到 1 为 9、到 25 为 15），25 单独成簇；新中心为 5.5 与 25，之后分配不变。

1. 两次都「收敛」了，却停在不同的局部最优，第一种的 SSE 是第二种的 2.5 倍以上。K-means 只保证 SSE 单调下降，不保证全局最优，所以实践中会用 K-means++ 初始化并多次重启。
2. 离群点 25 在第一种结果中把右侧簇的中心从 9 拉到了 13。均值对离群点敏感，必要时可以改用 K-medoids，或先处理离群点。

import numpy as np

def pca(X, k):
    Xc = X - X.____(axis=0)
    U, S, Vt = np.linalg.svd(Xc, full_matrices=False)
    components = Vt[____]
    explained_var = S[:k] ** 2 / (____)

2. `Vt[:k]`：中心化数据 $X_c=USV^\top$，$V$ 的列（即 `Vt` 的行）是 $X_c^\top X_c$ 的特征向量，也就是主成分方向，按奇异值从大到小排列，取前 $k$ 行。

**测试**检查了：主成分两两正交、解释方差等于协方差矩阵最大的特征值、投影后各维方差等于解释方差、保留全部成分时可以无损重构。

### FND-ML-016　进阶 · 考频 ★★

实现多分类的 macro-F1（不使用 scikit-learn）：

```python
def macro_f1(y_true: list, y_pred: list) -> float: ...
```

- 类别集合取 `y_true` 与 `y_pred` 中出现过的所有类别（类别可以是整数或字符串）；
- 对每个类别计算精确率、召回率和 F1，再对所有类别取算术平均；
- 精确率或召回率的分母为 0 时按 0 计；精确率与召回率都为 0 时，F1 按 0 计。不能抛出除零错误。

<details>
<summary>答案与解析</summary>

**参考实现：**

```python
def macro_f1(y_true, y_pred):
    classes = sorted(set(y_true) | set(y_pred))
    f1s = []
    for c in classes:
        tp = sum(t == c and p == c for t, p in zip(y_true, y_pred))
        fp = sum(t != c and p == c for t, p in zip(y_true, y_pred))
        fn = sum(t == c and p != c for t, p in zip(y_true, y_pred))
        prec = tp / (tp + fp) if tp + fp else 0.0
        rec = tp / (tp + fn) if tp + fn else 0.0
        f1s.append(2 * prec * rec / (prec + rec) if prec + rec else 0.0)
    return sum(f1s) / len(f1s)
```

**测试用例：**

```python
assert macro_f1([0, 1, 2, 2], [0, 1, 2, 2]) == 1.0
# 类别 0：P=1, R=0.5, F1=2/3；类别 1：P=0.5, R=1, F1=2/3；类别 2：F1=1
assert abs(macro_f1([0, 0, 1, 2], [0, 1, 1, 2]) - (2/3 + 2/3 + 1) / 3) < 1e-12
# 只出现在预测里的类别 3 也要计入：P=0、R=0 -> F1=0
assert abs(macro_f1([0, 0, 1, 1], [0, 3, 1, 1]) - (2/3 + 1 + 0) / 3) < 1e-12
# 某类从未被预测：召回为 0、F1 为 0，不能报除零错误
assert abs(macro_f1([0, 0, 0, 1], [0, 0, 0, 0]) - (2 * 0.75 * 1 / 1.75 + 0) / 2) < 1e-12
# 不平衡：准确率 0.9，但 macro-F1 只有约 0.47
y_t = [0] * 9 + [1]; y_p = [0] * 10
assert abs(macro_f1(y_t, y_p) - (2 * 0.9 / 1.9) / 2) < 1e-12
assert macro_f1(["cat", "dog"], ["cat", "dog"]) == 1.0
```

**解析：**

**思路**：对每个类别 $c$ 做「一对其余」的二分类统计：
- TP：真实为 $c$ 且预测为 $c$；
- FP：真实不是 $c$ 却预测为 $c$；
- FN：真实为 $c$ 却预测成别的类别。

然后 $P=\frac{TP}{TP+FP}$，$R=\frac{TP}{TP+FN}$，$F1=\frac{2PR}{P+R}$，最后对各类别的 F1 取平均。

**边界情况**：
- 某类从未被预测：$TP+FP=0$，精确率无定义，按 0 计（scikit-learn 默认也按 0 计并给出警告）；
- 某类只出现在预测中：召回率的分母为 0，F1 为 0。这一类也要计入平均，因为模型确实犯了错。

**复杂度**：$O(nC)$。数据量大时可以先构造 $C\times C$ 的混淆矩阵，再一次性得到所有类别的 TP（对角线）、FP（列和减对角线）、FN（行和减对角线），复杂度降为 $O(n+C^2)$。

<sub>考点：分类评估指标</sub>

<a name="FND-ML-020"></a>

### FND-ML-020　进阶 · 考频 ★★★

用 numpy 实现 AUC：

```python
def auc(scores, labels) -> float: ...
```

- `scores` 为模型得分，`labels` 为 0/1 标签，长度相同；
- 要求时间复杂度 $O(n\log n)$，不能两两比较；
- 得分相同的样本按「平均秩」处理（等价于并列的正负样本对记 0.5）；
- 只有一种类别时 AUC 无定义，抛出 `ValueError`。

<details>
<summary>答案与解析</summary>

**参考实现：**

```python
import numpy as np

def auc(scores, labels):
    scores = np.asarray(scores, dtype=float)
    labels = np.asarray(labels).astype(bool)
    n_pos, n_neg = int(labels.sum()), int((~labels).sum())
    if n_pos == 0 or n_neg == 0:
        raise ValueError("AUC 需要同时有正样本和负样本")
    ranks = np.empty(len(scores))
    ranks[np.argsort(scores, kind="mergesort")] = np.arange(1, len(scores) + 1)
    _, inv = np.unique(scores, return_inverse=True)        # 并列得分取平均秩
    ranks = (np.bincount(inv, weights=ranks) / np.bincount(inv))[inv]
    return float((ranks[labels].sum() - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg))
```

**测试用例：**

```python
def brute(scores, labels):
    pos = [s for s, l in zip(scores, labels) if l]
    neg = [s for s, l in zip(scores, labels) if not l]
    tot = sum(1.0 if p > n else 0.5 if p == n else 0.0 for p in pos for n in neg)
    return tot / (len(pos) * len(neg))

assert abs(auc([0.9, 0.7, 0.4, 0.8, 0.4, 0.3, 0.1], [1, 1, 1, 0, 0, 0, 0]) - 9.5 / 12) < 1e-12
assert auc([0.1, 0.2, 0.8, 0.9], [0, 0, 1, 1]) == 1.0
assert auc([0.1, 0.2, 0.8, 0.9], [1, 1, 0, 0]) == 0.0
assert auc([0.5] * 6, [1, 0, 1, 0, 1, 0]) == 0.5
rng = np.random.default_rng(0)
for _ in range(50):
    n = int(rng.integers(2, 40))
    sc = rng.integers(0, 5, n) / 4.0          # 大量并列得分
    lb = rng.integers(0, 2, n)
    lb[0], lb[1] = 0, 1
    assert abs(auc(sc, lb) - brute(sc, lb)) < 1e-12
big = rng.random(20000); lab = rng.random(20000) < 0.3
assert abs(auc(big, lab) - 0.5) < 0.02
for bad in ([1, 1, 1], [0, 0]):
    try:
        auc([0.3] * len(bad), bad)
        raise AssertionError("单一类别应抛出 ValueError")
    except ValueError:
        pass
```

**解析：**

**思路**：利用 AUC 与 Mann–Whitney U 统计量的关系。把所有样本按得分升序排列，赋秩 $1..n$；正样本的秩和减去 $\frac{n_{pos}(n_{pos}+1)}{2}$，就是「正样本得分高于负样本」的样本对数。

**为什么**：第 $k$ 小的正样本，秩为 $r_k$，排在它前面的样本有 $r_k-1$ 个，其中 $k-1$ 个是正样本，所以它胜过 $r_k-k$ 个负样本。对所有正样本求和得 $\sum_kr_k-\frac{n_{pos}(n_{pos}+1)}2$。

**并列处理**：一组并列的得分都取平均秩，等价于并列的正负样本对各记 0.5。实现中先按排序位置给出 $1..n$ 的秩，再用 `np.unique` 找到每个不同得分的分组，对组内的秩取平均。

**易错点**：
- 忽略并列：例如所有得分都相同时，正确结果是 0.5，忽略并列会得到依赖排序结果的错误值；
- 单一类别时除以 0：应显式报错；
- 两两比较是 $O(n^2)$，百万样本时不可行。

<sub>考点：ROC与AUC</sub>

</details>

### FND-ML-025　进阶 · 考频 ★★★

用 numpy 从零实现二分类逻辑回归（全批量梯度下降）：

def train_logreg(X, y, lr=0.1, epochs=1000, l2=0.0): ...  # 返回 (w, b)

<details>
<summary>答案与解析</summary>

**参考实现：**

```python
import numpy as np

def sigmoid(z):
    out = np.empty_like(z, dtype=float)
    pos = z >= 0
    out[pos] = 1.0 / (1.0 + np.exp(-z[pos]))
    ez = np.exp(z[~pos])                      # z<0 时改写成 e^z/(1+e^z)，避免溢出
    out[~pos] = ez / (1.0 + ez)
    return out

def train_logreg(X, y, lr=0.1, epochs=1000, l2=0.0):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        p = sigmoid(X @ w + b)
        err = p - y                           # dL/dz：预测减标签
        w -= lr * (X.T @ err / n + l2 * w)
        b -= lr * err.mean()
    return w, b

def predict_proba(X, w, b):
    return sigmoid(X @ w + b)
```

**测试用例：**

```python
rng = np.random.default_rng(0)
X = rng.normal(size=(400, 2))
w_true, b_true = np.array([2.0, -3.0]), 0.5
y = (rng.random(400) < 1 / (1 + np.exp(-(X @ w_true + b_true)))).astype(float)

# 1) 一步更新与手推梯度一致（初始 w=0、b=0 时 p 全为 0.5）
w1, b1 = train_logreg(X, y, lr=0.5, epochs=1)
assert np.allclose(w1, -0.5 * X.T @ (0.5 - y) / 400) and np.isclose(b1, -0.5 * (0.5 - y).mean())

# 2) 训练后：准确率高、平均损失低于 ln2、梯度接近 0
w, b = train_logreg(X, y, lr=0.5, epochs=3000)
p = predict_proba(X, w, b)
assert ((p > 0.5) == (y == 1)).mean() > 0.85
loss = -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))
assert loss < np.log(2) - 0.2
assert np.abs(X.T @ (p - y) / 400).max() < 1e-3
assert np.sign(w[0]) == 1 and np.sign(w[1]) == -1

# 3) L2 正则会收缩权重
w_reg, _ = train_logreg(X, y, lr=0.5, epochs=3000, l2=0.5)
assert np.linalg.norm(w_reg) < np.linalg.norm(w)

# 4) 数值稳定：特征放大 1000 倍也不出现 NaN / inf
w_big, b_big = train_logreg(X * 1000, y, lr=0.1, epochs=50)
assert np.all(np.isfinite(w_big)) and np.isfinite(b_big)
assert np.all(np.isfinite(predict_proba(X * 1000, w_big, b_big)))
```

**解析：**

**推导**：平均交叉熵 $L=\frac1n\sum_i[-y_i\log p_i-(1-y_i)\log(1-p_i)]$，$p_i=\sigma(w^\top x_i+b)$。利用 $\partial\ell_i/\partial z_i=p_i-y_i$：
$$\nabla_wL=\frac1nX^\top(p-y)+l2\cdot w,\qquad \frac{\partial L}{\partial b}=\frac1n\sum_i(p_i-y_i)$$

**实现要点**：
1. 向量化：一次矩阵乘得到所有样本的 logits，不对样本写循环；
2. 稳定的 sigmoid：$z\ge0$ 时用 $1/(1+e^{-z})$，$z<0$ 时用 $e^z/(1+e^z)$，指数部分永远不超过 1；
3. 正则项只加在 $w$ 上，梯度为 $l2\cdot w$；
4. 梯度要除以 $n$（对平均损失求导），否则学习率要随样本数调整。

**测试的设计**：第 1 条用「一步更新」对拍手推梯度；第 2 条检查收敛后梯度接近 0；第 3 条检查正则化的收缩效果；第 4 条检查数值稳定性。

**延伸**：面试中常被追问的点有：为什么用交叉熵而不用 MSE；线性可分时不加正则，$\lVert w\rVert$ 会无限增大；多分类推广到 softmax 回归，梯度形式同样是 $X^\top(P-Y)/n$。

<sub>考点：线性回归与逻辑回归</sub>

<a name="FND-ML-004"></a>

### FND-ML-004　进阶 · 考频 ★★★

请推导平方损失下的偏差-方差分解，说明每一项的含义；并说明在实际项目中如何判断模型主要受偏差还是方差拖累，以及各自的改进手段。

<details>
<summary>答案与解析</summary>

**参考答案：**

1. **设定**：$y=f(x)+\varepsilon$，$E[\varepsilon]=0$，$\mathrm{Var}(\varepsilon)=\sigma^2$。$\hat f_D$ 是在随机训练集 $D$ 上训练得到的模型，记 $\bar f(x)=E_D[\hat f_D(x)]$。
2. **分解**：在固定的 $x$ 处，
   $$E_{D,\varepsilon}\big[(y-\hat f_D(x))^2\big]=\underbrace{\sigma^2}_{\text{噪声}}+\underbrace{(f(x)-\bar f(x))^2}_{\text{偏差}^2}+\underbrace{E_D\big[(\hat f_D(x)-\bar f(x))^2\big]}_{\text{方差}}$$
   推导要点：先把 $y-\hat f$ 写成 $\varepsilon+(f-\hat f)$，由于 $\varepsilon$ 与 $D$ 独立且均值为 0，交叉项消失；再把 $f-\hat f$ 写成 $(f-\bar f)+(\bar f-\hat f)$，后一项关于 $D$ 的期望为 0，交叉项再次消失。
3. **含义**：
   - 噪声：数据本身不可约的误差，任何模型都消除不了；
   - 偏差：模型「平均来看」离真相有多远，反映模型假设是否太简单；
   - 方差：换一份训练集，预测会抖动多少，反映模型对训练数据的敏感程度。模型越复杂，一般偏差越小、方差越大，这就是权衡。
4. **判断**：比较训练误差、验证误差与期望水平（如人类水平或业务要求）：
   - 训练误差本身就高 → 偏差大；
   - 训练误差低、验证误差高得多 → 方差大；
   - 也可以画学习曲线（误差随样本量变化）或验证曲线（误差随模型复杂度变化）来辅助判断。
5. **对策**：
   - 降偏差：增大模型容量、加入更好的特征、减弱正则、训练更久、Boosting；
   - 降方差：增加数据或做数据增强、加强正则（L1 / L2、Dropout）、早停、降低复杂度、Bagging / 集成。

**评分要点（共 10 分）：**

- 写出正确的设定与三项分解式（3 分）
- 说明交叉项为何消失（推导要点）（2 分）
- 正确解释噪声、偏差、方差的含义及与复杂度的关系（2 分）
- 给出判断方法与对应的改进手段（3 分）

**讲解：**

**常见失分点**：把偏差写成未平方的形式，或漏掉噪声项；混淆期望是对谁求的（方差是对训练集 $D$ 的随机性求期望，不是对样本 $x$）；认为「加数据」对高偏差也很有效；把正则化说成降偏差的手段。

<sub>考点：偏差方差权衡、过拟合与欠拟合</sub>

</details>

<a name="FND-ML-031"></a>

### FND-ML-031　进阶 · 考频 ★★

请比较随机森林、GBDT 与 XGBoost（可兼谈 LightGBM）：它们的核心原理、主要降低的是偏差还是方差、训练能否并行、关键超参数有哪些？XGBoost 相对传统 GBDT 做了哪些改进？在表格数据项目中你会怎么选？

<details>
<summary>答案与解析</summary>

**参考答案：**

1. **随机森林**：Bagging + 每次分裂随机选特征子集。基学习器是深而不剪枝的树（低偏差、高方差），平均后主要降低**方差**。树与树之间相互独立，可以完全并行。关键超参数：树的数量、每次分裂考虑的特征数、最大深度或叶子最少样本数。还可以用袋外（OOB）样本估计泛化误差。对超参数不敏感，是很好的基线。
2. **GBDT**：Boosting，逐棵添加回归树，每棵树拟合损失关于当前预测的负梯度（函数空间的梯度下降）。基学习器是浅树（高偏差），主要降低**偏差**。树与树之间是串行的。关键超参数：学习率、树的数量（配合早停）、树深、子采样比例。
3. **XGBoost 的改进**（Chen 与 Guestrin, 2016）：
   - 二阶泰勒展开，同时利用梯度和二阶导数，叶子权重有闭式解；
   - 目标中显式加入正则项 $\gamma T+\frac12\lambda\lVert w\rVert^2$，用增益公式指导分裂和剪枝；
   - 列（特征）子采样：借鉴随机森林，与 Friedman 的 GBDT 中已有的 shrinkage、行子采样一起抑制过拟合；
   - 稀疏感知：为缺失值学习默认的分裂方向；
   - 工程上：加权分位数草图做近似分裂，按列分块存储，在单棵树内部并行寻找分裂点。
4. **LightGBM**（Ke 等, 2017）：直方图算法、按叶子生长（leaf-wise）、基于梯度的单边采样（GOSS）、互斥特征捆绑（EFB），训练更快、更省内存；按叶子生长需要限制叶子数或深度，以防过拟合。
5. **怎么选**：想快速得到稳健的基线、数据噪声大、不想多调参，用随机森林；追求最高精度，用 GBDT 系（XGBoost / LightGBM / CatBoost）并配合早停；数据量大、特征多时，优先选 LightGBM 或 XGBoost 的 hist 模式；类别特征很多时可以考虑 CatBoost。

**评分要点（共 10 分）：**

- 说清随机森林的原理、降方差、可并行（2 分）
- 说清 GBDT 拟合负梯度、降偏差、串行（2 分）
- 列出 XGBoost 的至少三项改进（二阶展开、正则项、缺失值处理、并行分裂等）（3 分）
- 给出关键超参数与选型建议（2 分）
- 提到 LightGBM 等变体的特点（1 分）

**讲解：**

**常见失分点**：说「GBDT 可以多棵树并行训练」（并行发生在单棵树内部）；把随机森林说成降偏差；只会背「XGBoost 用二阶导数」，说不出正则项与分裂增益的关系；以为增加树的数量对 GBDT 没有过拟合风险。

<sub>考点：决策树与集成学习　｜　出处：Breiman, Random Forests（Machine Learning, 2001）；Friedman, Greedy Function Approximation: A Gradient Boosting Machine（Annals of Statistics, 2001）；Chen 与 Guestrin, XGBoost: A Scalable Tree Boosting System, arXiv:1603.02754；Ke 等, LightGBM: A Highly Efficient Gradient Boosting Decision Tree（NeurIPS 2017）</sub>

</details>

<a name="FND-ML-034"></a>

### FND-ML-034　进阶 · 考频 ★★

请讲清支持向量机的核心思想：(1) 硬间隔 SVM 的优化目标是什么，为什么要最大化间隔；(2) 软间隔中的松弛变量与参数 $C$ 起什么作用，它与合页损失（hinge loss）有什么关系；(3) 为什么要转化为对偶问题，核技巧怎样用上；(4) SVM 的主要优缺点。

<details>
<summary>答案与解析</summary>

**参考答案：**

1. **硬间隔**：在线性可分的数据上找超平面 $w^\top x+b=0$，最小化 $\frac12\lVert w\rVert^2$，约束为 $y_i(w^\top x_i+b)\ge1$。间隔为 $2/\lVert w\rVert$。最大化间隔使分类边界离两类样本都尽量远，对扰动更稳健，也有更好的泛化保证。
2. **软间隔**：引入松弛变量 $\xi_i\ge0$，约束放宽为 $y_i(w^\top x_i+b)\ge1-\xi_i$，目标为 $\frac12\lVert w\rVert^2+C\sum_i\xi_i$。$C$ 越大，对违反间隔的惩罚越重，越接近硬间隔，容易过拟合；$C$ 越小，间隔越宽、容忍越多错误。它等价于无约束形式 $\frac12\lVert w\rVert^2+C\sum_i\max(0,1-y_if(x_i))$，即「合页损失 + L2 正则」。
3. **对偶与核技巧**：用拉格朗日对偶得到 $\max_\alpha\sum_i\alpha_i-\frac12\sum_{i,j}\alpha_i\alpha_jy_iy_jx_i^\top x_j$，约束为 $0\le\alpha_i\le C$、$\sum_i\alpha_iy_i=0$。对偶问题与预测函数 $f(x)=\sum_i\alpha_iy_ix_i^\top x+b$ 都只依赖样本之间的内积，把内积换成核函数 $K(x_i,x_j)$，就相当于在高维（甚至无穷维）特征空间中求线性分类器，而不需要显式映射。$\alpha_i>0$ 的样本就是支持向量。
4. **优缺点**：
   - 优点：凸优化，有全局最优解；样本不多、特征维度高时效果好；解是稀疏的（只依赖支持向量）；核函数可以灵活地刻画非线性。
   - 缺点：核方法的训练开销随样本数增长很快（核矩阵为 $n\times n$，训练复杂度约在 $O(n^2)$ 到 $O(n^3)$ 之间），难以用于百万级以上的数据；对核函数、$C$、$\gamma$ 敏感，需要调参；不直接输出概率（需要 Platt 缩放等校准）；多分类需要一对一或一对多的组合。

**评分要点（共 10 分）：**

- 写出硬间隔的目标与约束，说明间隔为 2/‖w‖ 及其意义（2 分）
- 说明松弛变量与 C 的作用，并联系合页损失 + L2 正则（3 分）
- 说明对偶问题只依赖内积，从而可以使用核技巧，并指出支持向量的含义（3 分）
- 给出主要优缺点（2 分）

**讲解：**

**常见失分点**：把间隔写成 $1/\lVert w\rVert$ 又不说明定义；说不清 $C$ 大小与过拟合的关系；以为核技巧需要先显式计算高维特征；忽略 SVM 在大规模数据上的扩展性问题；把 SVM 的输出当作概率使用。

<sub>考点：支持向量机</sub>

</details>

<a name="FND-ML-035"></a>

### FND-ML-035　进阶 · 考频 ★★★

请说明 K-means 的算法流程与优化目标，为什么它一定会收敛、却不一定收敛到全局最优；再说明它有哪些局限，以及对应的改进方法。

<details>
<summary>答案与解析</summary>

**参考答案：**

1. **流程**：随机选 $K$ 个初始中心 → 把每个样本分配给最近的中心 → 用每个簇的样本均值更新中心 → 重复分配与更新，直到分配不再变化（或中心移动小于阈值）。每轮复杂度 $O(nKd)$。
2. **目标**：最小化簇内平方误差和 $J=\sum_i\lVert x_i-\mu_{c(i)}\rVert^2$。
3. **收敛性**：分配步在中心固定时最优地选择归属，更新步在归属固定时用均值最优地选择中心，每一步都不会让 $J$ 增大；而可能的划分只有有限多种，所以一定在有限步内收敛。但这是坐标下降，只能保证收敛到局部最优，结果依赖初始中心。
4. **局限**：
   - 需要预先指定 $K$；
   - 对初始化敏感，可能陷入差的局部最优；
   - 基于欧氏距离、以均值为中心，隐含假设簇是大小相近、各向同性的凸形（球状）簇，无法处理环形、月牙形等非凸簇以及密度差异很大的簇；
   - 对离群点敏感（均值会被拉偏），对特征尺度敏感。
5. **改进**：
   - 初始化：K-means++（按与已选中心距离的平方成比例的概率选下一个中心），多次随机重启取 $J$ 最小的结果；
   - 选 $K$：肘部法、轮廓系数、gap statistic，或结合业务需要；
   - 先标准化特征；对离群点用 K-medoids / K-medians；
   - 椭圆形、需要软分配的簇用 GMM；非凸形状用 DBSCAN、谱聚类；
   - 数据量大时用 Mini-batch K-means。

**评分要点（共 10 分）：**

- 正确描述算法流程与目标函数（3 分）
- 解释为何单调收敛且只能保证局部最优（2 分）
- 列出至少三条局限（K 的选择、初始化、形状假设、离群点或尺度）（3 分）
- 给出对应的改进方法（K-means++、标准化、GMM、DBSCAN 等）（2 分）

**讲解：**

**常见失分点**：说 K-means「保证找到全局最优」；只说「对初始值敏感」却说不出 K-means++ 的做法；不知道 K-means 隐含了球状簇的假设；忘记先做特征标准化。

<sub>考点：聚类算法</sub>

</details>

## 场景分析题

<a name="FND-ML-022"></a>

### FND-ML-022　挑战 · 考频 ★★★

某支付平台训练了一个交易欺诈检测模型，欺诈交易约占 0.1%。离线测试显示准确率 99.9%，团队很满意；上线一周后风控同事反馈：几乎抓不到欺诈，偶尔报警的也多是误报。人工审核团队每天最多能复核 2000 笔可疑交易，平台每天约 100 万笔交易。请分析问题出在哪里，并给出从评估、训练到上线决策的改进方案。

<details>
<summary>答案与解析</summary>

**参考答案：**

**问题诊断**：
1. 指标选错：欺诈只占 0.1%，全部预测为正常就有 99.9% 的准确率，这个数字没有任何信息量。模型很可能退化成「几乎都判正常」。
2. 阈值不合理：默认用 0.5 作阈值，而少数类的预测概率普遍偏低，导致召回极低。
3. 可能还有评估方式问题：随机划分而不是按时间划分，离线表现与线上不一致。

**评估**：
- 改用正类的精确率、召回率、PR-AUC（AP），以及与业务直接相关的指标：在「每天 2000 笔复核量」下的召回率（Recall@K）与命中率（Precision@K），每天拦截的欺诈金额等；
- 按时间切分训练集、验证集与测试集，模拟「用过去预测未来」；同一用户或同一商户的样本避免同时出现在训练集和测试集中。

**训练**：
- 类别加权或 Focal Loss；或对负样本欠采样（如 1:10），同时保留全量验证集；
- 特征上加入行为序列、设备与关系特征（同一设备或卡的关联账户）、交易速度等；
- 用 GBDT 这类适合表格数据的强基线；注意特征只能使用交易发生时刻之前的信息，避免穿越。

**上线决策**：
- 阈值由审核能力与代价决定：每天 100 万笔，复核 2000 笔，相当于取得分最高的 0.2%。在验证集上评估「Top 0.2% 的召回率与精确率」，并据此确定阈值；也可以按期望代价（漏判损失 × 欺诈概率 vs 误拦成本）分层处理：高分直接拦截，中分人工复核，低分放行；
- 如果下游要用概率（如计算期望损失），对欠采样或加权训练后的模型重新校准（先验校正或 Platt 校准）。

**监控与迭代**：监控每日报警量、复核命中率与得分分布的漂移；把人工复核结果回流为新标签；欺诈手法变化快，需要定期重训，并对新型欺诈做专项评估。

**评分要点（共 10 分）：**

- 指出准确率陷阱与默认阈值是主要问题（2 分）
- 给出合适的评估指标与时间切分等评估方案（2 分）
- 给出类别不平衡的训练手段（加权、Focal、欠采样等）（2 分）

- 提到线上监控、反馈回流与定期重训（1 分）

**常见失分点**：只回答「过采样 + SMOTE」，不讨论指标与阈值；对测试集也做重采样；不结合「每天 2000 笔」的审核能力来确定阈值；忽视时间切分与特征穿越，导致离线表现虚高。高分回答应把指标、训练和上线决策串成一条链，并用数字说明阈值是如何确定的。

<a name="FND-ML-043"></a>

### FND-ML-043　挑战 · 考频 ★★

团队做用户流失预测：预测「用户在未来 30 天内是否流失」。数据是一张宽表，每个用户一行，包含近 100 个特征，例如「最近 7 天登录次数」「累计消费金额」「是否申请过退款」「客服工单中提到『注销』的次数」，标签取自上个月的流失情况。随机切分 5 折交叉验证得到 AUC 0.97；上线一个月后，实际 AUC 只有 0.62。请分析可能的原因，并给出排查与修正方案。

<details>
<summary>答案与解析</summary>

**参考答案：**

**可能的原因**：
1. **特征穿越（时间泄露）**：宽表的特征是在「抽数那一刻」计算的，而不是在「预测时刻」计算的。例如「最近 7 天登录次数」对已流失用户天然接近 0，「提到注销的工单数」往往发生在流失决定之后。这些特征包含了标签窗口之内甚至之后的信息，离线时近乎「答案」，上线时还没有发生，自然失效。
2. **目标泄露**：有些特征本身就是流失的结果或同义词（如退款、注销申请），属于标签的一部分。
3. **评估方式不当**：随机切分，没有按时间切分，训练集与验证集来自同一时期，离线分数偏高；同一用户（或同一家庭、同一企业）的多条记录分散到训练集和验证集，模型会「认人」。
4. **分布漂移**：上线时期的用户结构、活动与产品版本和训练期不同。

**排查**：
- 看特征重要性：AUC 高达 0.97 时，先怀疑那些单独看就极强的特征，逐个检查它的计算时间点与业务含义；
- 单特征 AUC 分析：某个特征单独的 AUC 接近整体 AUC，往往就是泄露；
- 逐一剔除可疑特征，按时间切分重新评估，看离线指标是否下降到合理水平；
- 对比线上与离线的特征分布（如 PSI），发现计算口径不一致的特征。

**修正**：
1. **按时间点构建样本**：为每个用户选定观察时刻 $t$，特征只用 $t$ 之前的数据计算（point-in-time join，特征平台的快照或特征存储），标签取 $(t,t+30\text{天}]$ 的流失情况；可以为同一用户在多个观察时刻构造多条样本。
2. **评估**：按时间做前向验证（如用 1～6 月的观察时刻训练、7 月验证），并按用户分组切分。
3. **治理**：建立特征准入规范，写清每个特征的可用时间；对线上与离线的特征一致性做自动校验；上线前先影子运行（shadow），对比线上预测与真实结果。
4. **预期**：修正后离线 AUC 会明显下降（比如到 0.75 左右），但这才是可信的、能与线上对齐的数字。

**评分要点（共 10 分）：**

- 指出特征穿越或时间泄露是主因，并举出具体特征说明（3 分）
- 指出随机切分、同一用户跨集合等评估问题（2 分）
- 给出系统的排查方法（特征重要性、单特征 AUC、分布对比等）（2 分）
- 给出按时间点构建特征与时间切分评估的修正方案（2 分）
- 提到特征一致性校验、影子上线等工程保障（1 分）

**讲解：**

**常见失分点**：把问题归因于「模型过拟合」，建议加正则或换模型；没有意识到宽表特征的计算时间晚于预测时刻；只说「换成时间切分」，却不说特征也要按时间点重新计算。离线 AUC 高得离谱（0.97）本身就是泄露的强烈信号，高分回答要先抓住这一点。

<sub>考点：特征工程、交叉验证</sub>

</details>
