## 一、单选题（每题 2 分，共 30 分）

**1.** 关于 5 折交叉验证（5-fold cross validation），下列描述正确的是：

- A. 每次随机抽取 20% 的样本作为验证集、其余训练，重复 5 次，同一个样本可能多次被用于验证
- B. 数据分成 5 份，轮流用 4 份训练、1 份验证，共训练 5 个模型，每个样本恰好验证一次，结果取平均
- C. 只在全部数据上训练 1 个模型，再把数据分成 5 份分别评估，取 5 份成绩的平均作为最终成绩
- D. 交叉验证的平均成绩可以直接作为最终的测试成绩，因此用交叉验证调参后，不再需要独立的测试集

**2.** 关于梯度消失与梯度爆炸的应对，下列说法正确的是：

- A. 梯度裁剪按全局范数重新缩放梯度：范数过大时等比例缩小、过小时等比例放大，因此对消失与爆炸都有效
- B. 梯度消失只出现在循环网络的长序列上；前馈网络层数有限，主要问题是梯度爆炸
- C. 梯度消失时，把学习率按浅层梯度衰减的倍数调大，就能让浅层恢复正常的更新幅度
- D. 裁剪只能对付梯度爆炸；梯度消失要靠 ReLU 类激活、残差连接、归一化与合适的初始化等手段缓解

**3.** 用 LoRA 微调 7B 模型，模型状态只有约 14 GB；但把序列长度从 2K 提到 16K 后，在 80 GB 的卡上仍然 OOM。最可能的原因和最直接的缓解办法是：

- A. LoRA 支路的参数需要为每个位置各存一份，参数量随序列长度线性增长；应减小秩 r
- B. Adam 要为每个 token 的梯度分别保存一阶矩和二阶矩，优化器状态随序列增长；应改用 SGD
- C. 长序列下冻结的底座权重要按序列分块复制到多个流上并行计算；应改用 QLoRA 压缩底座
- D. 激活显存随序列长度增长，而 LoRA 不减少激活；应开启梯度检查点，必要时减小 micro-batch

**4.** 关于 Triton，下列说法正确的是：

- A. OpenAI Triton 是 NVIDIA Triton 推理服务器的前身，主要用于部署和管理模型服务
- B. Triton 是生成 CUDA C++ 源码的模板工具，程序员仍要以单个线程为单位编写下标与同步
- C. 编译器能做全局优化，Triton kernel 在 Hopper 上普遍快于手写 CUTLASS，FlashAttention-3 也因此用 Triton 实现
- D. OpenAI 的 Triton 是用 Python 写 GPU kernel 的语言与编译器，以「块」为单位编程，块内线程映射由编译器完成

**5.** BLIP-2 用 Q-Former 连接冻结的图像编码器与冻结的语言模型。关于 Q-Former，下列说法正确的是：

- B. 它把每个图像 patch 都一一投影成语言模型的 token，因此视觉 token 数等于 patch 数
- C. 它从第一阶段起就接上语言模型端到端训练，只用语言建模损失，不需要图文对比等目标
- D. 第二阶段解冻整个大语言模型，与 Q-Former 一起用语言建模损失端到端更新

**7.** DeepSeek-R1 论文用 R1 生成的约 80 万条样本（含推理与非推理数据）对 Qwen、Llama 系列的较小稠密模型直接做 SFT（即蒸馏），并与「直接对 Qwen-32B-Base 做大规模强化学习」进行了对比。论文得出的结论是：

- A. 蒸馏出的 32B 模型明显优于直接做大规模 RL 的 32B 模型，后者只与 QwQ-32B-Preview 相当
- B. 直接做大规模 RL 的 32B 模型明显优于蒸馏模型，说明小模型靠自身探索能学到更强的推理能力

**8.** 关于「开放权重（open weights）」与「开源（open source）」的区别，下列说法最准确的是：

- A. 权重可公开下载且允许商用，就符合 OSI 对开源 AI 的定义，代码与数据不在考虑范围内
- B. OSI《开源 AI 定义》要求以认可的条款提供参数、完整代码和足够详细的数据信息
- C. 按 OSI 的定义，开源 AI 必须公开全部原始训练数据，涉及版权的数据也不能例外
- D. 权重以 Apache 2.0 许可发布，就自动满足 OSI《开源 AI 定义》的全部要求

**9.** Mamba 的「选择性」机制让 SSM 的参数 $\Delta$、$B$、$C$ 由当前输入计算得到；离散化后 $\bar A=\exp(\Delta A)$，其中 $A$ 的取值使状态随时间衰减（实部为负）。关于步长 $\Delta$ 的作用，下列理解正确的是：

- A. $\Delta$ 只是数值积分的精度参数，取值越小离散化越精确，与模型对信息的取舍无关
- B. $\Delta$ 越大，$\bar A$ 越接近 1，模型越倾向于保留旧状态、忽略当前输入
- C. $\Delta$ 大时旧状态被大幅遗忘、聚焦当前输入；$\Delta$ 小时状态保持、跳过当前输入
- D. Mamba 的 $\Delta$ 对所有 token 取同一个可学习常数，选择性来自矩阵 $A$ 随输入变化

**10.** PagedAttention 论文报告，其注意力 kernel 比 FasterTransformer 中的实现慢约 20%～26%，但 vLLM 的端到端吞吐却比 FasterTransformer、Orca 高 2～4 倍。对此最准确的解释是：

- A. 吞吐提升主要来自并行采样、束搜索中的 KV 共享，普通的单序列采样下 vLLM 并无优势
- B. 分页让活跃序列的 KV 常驻 L2 缓存，命中率的提升抵消了间接寻址带来的 kernel 开销
- C. PagedAttention 减少了注意力的计算量，省下的算力抵消了 kernel 变慢的损失
- D. 分页把 KV 显存浪费降到 4% 以下，batch 能大几倍，这部分收益远大于 kernel 的损失

**11.** 在一个狭长的「山谷」形损失面上（一个方向很陡，另一个方向很平缓），普通梯度下降的轨迹会在陡峭方向上来回振荡，在平缓方向上进展缓慢。加入动量（$v\leftarrow\mu v+g$，$\theta\leftarrow\theta-\eta v$）后能够改善，原因是：

- A. 动量让每一步都沿当前最陡的方向走得更远，在两侧谷壁之间加速弹跳，从而更快地离开山谷
- B. 动量相当于对学习率做指数衰减：$\mu$ 越大，学习率衰减越快，振荡幅度也随之逐步减小
- C. 动量累积历史梯度：陡峭方向的梯度正负交替、相互抵消，平缓方向的梯度持续累积，等效步长变大
- D. 动量通过历史梯度的差分近似海森矩阵，按牛顿方向选择更新，因此能沿山谷底部前进

**12.** EAGLE（Li 等, 2024）的草稿头与 Medusa 的解码头相比，最关键的不同在于：

- A. 它在特征层面自回归：用顶层特征与提前一步的 token 预测下一个特征，再经 LM head 得到草稿
- B. 它不用训练：直接截取目标模型的前几层作为草稿，跳过后面的层来快速猜测 token
- C. 它的多个头彼此独立、都从同一个隐状态出发，同时预测未来不同位置的 token，因此可以并行
- D. 它用 Jacobi 迭代并行猜测后续 token，把迭代轨迹中的 n-gram 当作草稿，不用额外参数

**13.** 在 H100（BF16 拐点约 295 FLOP/B）上服务 8B 模型。若把 Chunked Prefill 的每步 token 预算设得很小（例如 64），最主要的副作用是：

- A. 长提示词被切开后，后面的块看不到前面块的 token，注意力只在块内计算，KV Cache 会算错
- B. 每步都夹带 Prefill 块并多读一遍权重，正在 Decode 的请求的 ITL 会明显变长
- C. 每步 token 太少，算术强度远低于拐点，算力利用率低，长提示词的 TTFT 明显变长
- D. 分块后各块是分步写入的，块哈希与完整提示词不一致，前缀缓存会因此失效

**14.** 训练 Decoder-only 的 MoE 模型时，某个专家收到的 token 超出了容量。有人提议：不按 token 在序列中的先后顺序决定丢弃谁，而是在整个序列（包括位置靠后的 token）里比较路由分数，优先保留分数高的 token（ST-MoE 中称为 Batch Prioritized Routing）。这样做的主要问题是：

- A. 需要对整个批次的路由分数做全局排序，开销随序列长度平方增长，大规模训练难以承受
- B. 分数高的 token 往往集中在少数热门专家上，按分数保留会让专家负载更加不均衡
- C. token 的去留取决于后面 token 的路由分数，相当于训练时偷看未来，推理时无法复现
- D. 优先保留的高分 token 会在多个专家中被重复计算，抵消了 MoE 稀疏计算的收益

**15.** 下列对投机采样实现的改动中，会破坏「输出分布与目标模型一致」（无损性）的是：

- A. 每轮根据上一轮的接受情况动态调整草稿长度 γ

- C. 草稿模型用温度 0.5 采样，但接受判断时用温度 1.0 下草稿给出的概率作为 q

## 二、多选题（每题 3 分，共 18 分）

**16.** 关于常见的概率分布，下列说法**正确**的有：

- A. 若 $X\sim\mathcal{N}(\mu,\sigma^2)$，则 $e^X$ 的均值为 $e^{\mu+\sigma^2/2}$，而不是 $e^{\mu}$
- B. 泊松分布 $\mathrm{Poisson}(\lambda)$ 的均值和方差都等于 $\lambda$
- C. $U(-a,a)$ 的方差为 $a^2/3$；Xavier 均匀初始化取 $a=\sqrt{6/(n_{in}+n_{out})}$，对应方差 $2/(n_{in}+n_{out})$
- D. 伯努利分布 $\mathrm{Bern}(p)$ 的方差为 $p(1-p)$，在 $p=0.5$ 时最大
- E. 拉普拉斯分布 $p(x)\propto e^{-|x|/b}$ 的尾部比高斯分布更轻，用它建模噪声时对离群点更敏感

**17.** 与全参数微调相比，LoRA 微调**明显减少**了下列哪些开销？

- A. 前向传播的计算量
- B. 冻结权重的梯度与优化器状态所占的显存
- C. 反向传播中对冻结权重求梯度的计算
- D. 前向传播中为反向保存的激活所占的显存
- E. 每个任务需要保存和分发的检查点大小

**18.** 关于大语言模型的知识蒸馏，下列说法**正确**的有：

- A. 序列级蒸馏要求教师提供每个位置的完整概率分布（logits），因此不适用于只能通过 API 调用的黑盒教师
- B. 在线（on-policy）蒸馏让学生自己生成序列，再由教师在这些序列上逐 token 给出监督，可以缓解训练与推理分布不一致的问题
- C. 蒸馏一定要求教师比学生大，同等规模的模型之间无法蒸馏
- D. logits（token 级）蒸馏要求教师与学生使用相同的分词器和词表，否则需要额外做词表对齐
- E. 前向 KL $\mathrm{KL}(p_{teacher}\Vert q_{student})$ 具有「寻找众数」（mode-seeking）的特点，会让学生只集中在教师的一个高概率模式上

**19.** 关于扩散模型的关键技术，下列说法**正确**的有：

- A. DiT 用 Transformer 替代 U-Net 作去噪网络，论文发现 Gflops 越大，FID 通常越好
- B. 无分类器引导把有条件与无条件的噪声预测外推组合，引导系数越大越贴合提示、多样性越低
- C. 潜空间扩散在 VAE 的低维潜空间中去噪，比直接在像素空间去噪节省大量计算
- D. 扩散模型一次前向传播就能从纯噪声得到最终图像，因此生成速度天然快于自回归模型
- E. DDIM 必须使用与训练时相同的 1000 步，只是把每步的随机采样换成了确定性更新

**20.** 关于大模型训练中的 on-policy 与 off-policy，下列说法**正确**的有：

- A. 即使训练端与推理引擎加载的权重完全相同，两者算出的 token 概率也可能有数值差异，这同样会造成轻微的 off-policy
- B. 异步 RL 中推理端用落后一两个版本的权重生成样本，训练数据带有陈旧度，同样属于轻微的 off-policy
- C. DPO 在事先收集好的偏好数据上训练，数据往往来自其他模型，属于离线（off-policy）学习
- D. PPO 把一批 rollout 切成多个 mini-batch 更新多轮，第一次更新之后，后面的 mini-batch 严格来说已经轻微 off-policy，靠重要性比率和裁剪来修正
- E. on-policy 算法只要保存好旧数据，就可以像 DQN 一样不加修正地从回放池中反复采样训练

**21.** 关于 EAGLE 系列的后续版本，下列说法正确的有：

- A. EAGLE 系列的草稿头针对具体的目标模型训练，目标模型更换或重新微调后，通常需要重新训练草稿头
- B. EAGLE-3 的草稿头需要与目标模型同样规模，才能达到较高的接受率
- C. EAGLE-3 放弃「预测特征」的约束，改为直接预测 token，并融合目标模型低、中、高多层的特征
- D. EAGLE-2 发现候选的接受率主要取决于它在树中的位置、与上下文关系不大，因此离线为每个位置设定固定的分支数
- E. EAGLE 系列为了提高速度放弃了无损性，输出分布与目标模型略有不同
